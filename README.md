# بوت القرآن الكريم (تيليجرام)

بوت جاهز بلغة بايثون يوفّر:

- 📖 **المصحف للقراءة**: نص كامل لأي سورة (114 سورة) بأي لغة تختارها.
- 🎲 **سورة عشوائية**: اختيار وقراءة سورة عشوائية بضغطة زر.
- 🌐 **اختيار لغة**: عربي + عدة ترجمات (إنجليزي، فرنسي، أردو، إندونيسي، تركي، روسي، إسباني، ألماني، فارسي) عبر واجهة alquran.cloud المجانية.
- ⚙️ **اختيارات متقدمة**:
  - **اختيار القارئ** مصنّفاً حسب **الروايات (القراءات العشر)** — البيانات تُجلب مباشرة وبشكل حي من واجهة `mp3quran.net`، وتغطي أكثر من 60 قارئاً بمختلف الروايات دون الحاجة لإدخالهم يدوياً.
  - **أذكار الصباح** (نص جاهز + إمكانية إرفاق ملف صوتي).
  - **فضل قراءة القرآن** (نص).
- 🔙 زر "رجوع" في كل قائمة فرعية للعودة للقائمة السابقة.
- 📢 زر ثابت في القائمة الرئيسية ينقل المستخدم مباشرة إلى قناتك: `@x7oly`.

## التثبيت والتشغيل

```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن_الذي_حصلت_عليه_من_BotFather"
python bot.py
```

على ويندوز (Powershell):
```powershell
$env:BOT_TOKEN="التوكن"
python bot.py
```

## ملاحظات مهمة

1. **مصدر بيانات القراء**: البوت يتصل بواجهة `https://www.mp3quran.net/api/v3/reciters`
   في كل مرة يُشغَّل فيها (أول طلب فقط، ثم يُخزَّن محلياً في الذاكرة). إن تغيّرت
   بنية هذه الواجهة مستقبلاً، قد تحتاج لتحديث أسماء الحقول في دالة
   `load_reciters()`.
2. **رابط الصوت**: يُبنى تلقائياً بصيغة `server/الرقم.mp3` وهي الصيغة
   المعتمدة في خوادم mp3quran.net. تأكد من صحة الرابط بتجربته إن واجهت مشكلة
   في قارئ معيّن.
3. **أذكار الصباح الصوتية**: ضع رابط ملف mp3 مباشر (أو مساراً على خادمك) في
   المتغيّر `MORNING_ATHKAR_AUDIO` أعلى ملف `bot.py`. تركه فارغاً يعرض النص فقط.
4. **نص أذكار الصباح وفضل القراءة**: نصوص مختصرة قابلة للتعديل والاستبدال
   بالكامل حسب رغبتك داخل `bot.py` (المتغيّرات `MORNING_ATHKAR_TEXT` و
   `VIRTUE_TEXT`).
5. البوت يستخدم مكتبة `python-telegram-bot` الإصدار 21 (غير متزامن/async).

## هيكلة الأزرار (باختصار)

```
القائمة الرئيسية
├── 📖 المصحف للقراءة → قائمة 114 سورة (صفحات) → نص السورة
├── 🎲 سورة عشوائية → نص سورة عشوائية مباشرة
├── 🌐 اختيار اللغة → قائمة اللغات
├── ⚙️ اختيارات متقدمة
│   ├── 🎙️ اختيار القارئ
│   │   └── اختيار الرواية → اختيار القارئ → اختيار السورة → إرسال الصوت
│   ├── 🌅 أذكار الصباح (نص + صوت اختياري)
│   └── ✨ فضل قراءة القرآن (نص)
└── 📢 قناة البوت (رابط مباشر لـ @x7oly)
```

كل قائمة فرعية تحتوي زر "🔙 رجوع" يعيدك للقائمة الأعلى مباشرة.
