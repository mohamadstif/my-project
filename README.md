# بوت القرآن الكريم (تيليجرام) — نسخة القائمة الثابتة

نسخة محدّثة تحاكي تجربة البوتات الاحترافية (قائمة أزرار ثابتة أسفل الشاشة بدل الأزرار المرفقة بكل رسالة)، مع:

- ⌨️ **قائمة أزرار ثابتة (Reply Keyboard)** لا تختفي مهما تصفّحت الرسائل.
- 📖 **المصحف**: قراءة نص أي سورة بأي لغة.
- 🎙️ **القراء**: اختر الحرف الأول من اسم القارئ (أو «الكل») → اختر القارئ → اختر الرواية → اختر السورة → استمع.
- 📜 **الروايات**: اختر الرواية أولاً → اختر القارئ من ضمنها → اختر السورة.
- 📄 **بالسورة** (داخل الاختيار المتقدم): اختر سورة أولاً ليعرض لك كل القراء الذين سجّلوها.
- 🎲 **عشوائي**: سورة عشوائية فوراً.
- ⚡ **اختيار سريع**: اختصار مباشر لتدفّق اختيار القارئ.
- ⚙️ **اختيار متقدم**: قائمة فرعية (بالسورة / بالقارئ / بالرواية / فضل قراءة القرآن).
- 🌅🌙 **أذكار الصباح والمساء** (نص + صوت اختياري).
- 📕📚 **القرآن الكريم PDF / تفسير القرآن PDF** (تحتاج تضع الروابط بنفسك).
- 🌐 **تغيير اللغة**.
- 📢 **قناة البوت**: زر يفتح رابط قناتك مباشرة `@x7oly`.
- ⬅️ أزرار "اختيار قارئ آخر" و"اختيار سورة أخرى" و"القائمة الرئيسية" و"التالي/السابق" للتنقل السلس.

## التثبيت والتشغيل

```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن_من_BotFather"
python bot.py
```

على ويندوز (Powershell):
```powershell
$env:BOT_TOKEN="التوكن"
python bot.py
```

## كيف يعمل داخلياً (مهم لو حبيت تعدّل)

البوت يعتمد على **آلة حالة بسيطة** مخزّنة في `context.user_data`:
- `step`: الخطوة الحالية (مثلاً `qari_letter`, `riwayah_surahs`...).
- `items` + `page`: القائمة الكاملة للعناصر ورقم الصفحة الحالية (للتصفّح).
- `candidates`: خريطة "نص الزر الظاهر" → "القيمة الحقيقية" للصفحة المعروضة حالياً.
- `on_extra_nav`: دالة تُستدعى عند الضغط على زر رجوع خاص مثل "اختيار قارئ آخر".

كل شاشة قائمة (سور، قراء، روايات...) تُبنى عبر دالة عامة واحدة `show_list()` و`render_page()`،
فبإمكانك إضافة أي قائمة جديدة بسهولة دون تكرار الكود.

## ملاحظات مهمة

1. **بيانات القراء** تُجلب حيّة من `mp3quran.net` (أول تشغيل فقط، ثم تبقى محفوظة بالذاكرة
   طوال عمل العملية). أكثر من 60 قارئاً بجميع الروايات تلقائياً دون إدخال يدوي.
2. **روابط الصوت** تُبنى تلقائياً بصيغة `server/الرقم.mp3` المعتمدة في mp3quran.net.
3. **PDF**: البوت لا يملك ملفات PDF افتراضية؛ ضع روابط مباشرة في `QURAN_PDF_URL` و`TAFSIR_PDF_URL`
   أعلى `bot.py`، وإلا سيخبر المستخدم أن الرابط غير مُعدّ بعد.
4. **الأذكار**: نصوص مختصرة قابلة للاستبدال الكامل في `MORNING_ATHKAR_TEXT` / `EVENING_ATHKAR_TEXT`،
   مع إمكانية إرفاق رابط صوتي في `MORNING_ATHKAR_AUDIO` / `EVENING_ATHKAR_AUDIO`.
5. تجميع القراء بالحرف الأول يعتمد على أول حرف من الاسم (بعد توحيد أشكال الألف: أ/إ/آ → ا)،
   وهو تبسيط قد يجمع أسماء كثيرة تبدأ بـ"ال" تحت حرف الألف — عدّله في `normalize_letter()` لو أردت تدقيقاً أكبر.
